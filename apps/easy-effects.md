EasyEffects Setup & Presets
Installation (Flatpak User Space)
```

flatpak install --user flathub com.github.wwmm.easyeffects -y

```

Presets Installation
Automated installer for community presets (including Dolby Atmos / IRS files):

```

bash -c "$(curl -fsSL https://raw.githubusercontent.com/JackHack96/EasyEffects-Presets/master/install.sh)"

```

Flatpak config path: `~/.var/app/com.github.wwmm.easyeffects/config/easyeffects/`
